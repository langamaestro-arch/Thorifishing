# Thorifishing 🎣

Mod independiente de pesca realista y RPG para Minecraft Java con NeoForge.

**Estado:** diseño y preparación. Todavía no existe un JAR instalable ni una compilación verificada.

**Objetivo:** Minecraft Java 26.3, sujeto a verificar la disponibilidad del MDK y las dependencias NeoForge.

## Funciones previstas
- Cinco niveles de pescador y experiencia persistente.
- Catálogo de 30 especies por bioma, con rareza, longitud y peso.
- Minijuego de tensión del sedal y HUD pixel art.
- Cañas, cebos y mejoras.
- Posteriormente: tesoros, acuarios, jefes y torneos.

Sin integración ni dependencia de EvolutionCraft ni otros mods propios.
